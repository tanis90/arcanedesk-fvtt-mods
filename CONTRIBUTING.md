# Contributing

Open an issue or pull request with the concrete problem, supported Foundry/module versions, and reproduction steps.
Run `npm ci` and `npm run verify` before submitting. Include a focused regression test for behavior changes.

Do not include rulebook excerpts, unauthorized translations, third-party assets, actual player/world exports,
credentials or local machine paths. State the source and license for any contributed dependency or asset.

Accepted changes are incorporated into the maintainer's development source before being exported to this repository.
The integration preserves author attribution and links the original contribution. Private data is never needed to
build or test this public tree. Changes to module identifiers or existing user data require an explicit migration design.
